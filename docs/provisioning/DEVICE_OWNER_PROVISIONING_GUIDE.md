# Android Enterprise Device Owner (DO) Provisioning Guide
## How FamilyGuard Enforces Tamper-Proof Parental Controls

Modern Android (API 29+) prevents regular applications from secretly suspending apps, killing processes, or overriding security settings. **Android Enterprise Device Owner (DO)** mode is the official, legal, and robust Google mechanism designed for fully managed devices.

---

### Provisioning Methods

#### Method 1: Zero-Touch 6-Tap QR Code Provisioning (Production Mode)
This method is used on a new phone or immediately following a **Factory Reset**:
1. Power on the factory-reset Android device.
2. On the initial "Welcome" / "Hi there" language selection screen, **tap the empty space on the screen 6 times consecutively**.
3. Android launches the built-in system QR code scanner.
4. Scan the QR code generated by the Parent App (`GET /api/v1/enrollment/enterprise-qr`).
5. Android automatically connects to Wi-Fi, downloads the FamilyGuard Child App, installs it, and assigns it **Device Owner** status before any personal accounts can be added.
6. The setup completes cleanly with full enterprise-level protections active.

---

#### Method 2: ADB Shell Provisioning (Free Development & Emulator Testing)
For rapid local testing on physical devices or Android Virtual Devices (AVD) without factory resetting:
1. Ensure the device has **Developer Options** and **USB Debugging** enabled.
2. In **Settings -> Accounts**, remove all existing accounts (e.g. Google, Samsung, Exchange).
   *(Android security prevents setting a Device Owner if any account is already bound).*
3. Install the Child App APK:
   ```bash
   adb install child_app/app/build/outputs/apk/debug/app-debug.apk
   ```
4. Run the provisioning command:
   ```bash
   adb shell dpm set-device-owner org.familyguard.child/.dpc.ParentalDpcReceiver
   ```
5. Android returns:
   ```text
   Success: Device owner set to package ComponentInfo{org.familyguard.child/org.familyguard.child.dpc.ParentalDpcReceiver}
   ```
6. The Child App now possesses permanent Device Owner privileges.

### Verifying Device Owner Status

To verify programmatically on the child device:
```kotlin
val dpm = context.getSystemService(Context.DEVICE_POLICY_SERVICE) as DevicePolicyManager
val isOwner = dpm.isDeviceOwnerApp(context.packageName)
```

To verify via ADB terminal:
```bash
adb shell dumpsys device_policy
```
Look for:
```text
Device Owner:
  admin=ComponentInfo{org.familyguard.child/org.familyguard.child.dpc.ParentalDpcReceiver}
  name=FamilyGuard Device Policy Controller
  package=org.familyguard.child
```

### Essential Capabilities Enabled by Device Owner

1. **`setPackagesSuspended(admin, packages, suspended)`**:
   - Greys out prohibited apps on the home screen and app drawer.
   - Prevents apps from running in the background.
   - Blocks launching with a customized parent message.
2. **`setKeyguardDisabledFeatures(admin, which)`**:
   - Disables access to camera/unauthorized controls from the lock screen.
3. **`setApplicationRestrictions(admin, "com.android.chrome", bundle)`**:
   - Passes `URLBlocklist` and `URLAllowlist` to Google Chrome to enforce web filtering without VPN overhead.
4. **`setAutoTimeRequired(admin, true)`**:
   - Locks the system clock to network time, preventing children from changing the phone date/time to bypass screen time limits.
5. **`setUninstallBlocked(admin, packageName, true)`**:
   - Prevents the child or unauthorized parties from uninstalling the protection app.
6. **Guaranteed Emergency Calling Exemption**:
   - The default telecom dialer (`TelecomManager.getDefaultDialerPackage`) and emergency numbers (`911`, `112`, `999`) are **never suspended**.
